# Política de seguridad

## Cómo comunicar un problema de seguridad
Si detectas un posible problema de seguridad, comunícalo directamente al responsable del repositorio (mrtcebjj) por un canal privado del equipo. No publiques los detalles en una Issue pública.

## Información sensible
- Nunca publiques contraseñas, tokens, claves privadas ni credenciales reales en Issues, Pull Requests, capturas o commits.
- La configuración local se guarda en `.env`, que no se versiona. Usa `.env.example` como referencia.
- Si una credencial real se expone, se revoca inmediatamente y se genera una nueva.
